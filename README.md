# screenshot address

a small mod to suffix the server ip to screenshot filenames

![img.png](marketing/img.png)
![img.png](marketing/img.png)

## suffixes

- when in singleplayer, it will be `_singleplayer`
- when outside a world (in menus, etc), it will be `_menus`
- when in multiplayer, it will be:
  - with no port in the address, `_[server host]`
  - with a port in the address, `_[server host]_[port]`
